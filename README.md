#  NBA Win Prediction Projects

A Python machine learning model that predicts home wins in
NBA games based on game statistics (shots, rebounds, assists, etc.).

## Results
- Model accuracy: 83%
- Most influential variable: field goal percentage (FG%)

## Tech Stack
Python, pandas, scikit-learn, matplotlib, seaborn, Jupyter Notebook

## Project Structure
- `notebooks/01_exploration.ipynb`: data exploration
- `notebooks/02_modeling.ipynb`: model training and evaluation
- `outputs/figures/`: generated graphs
